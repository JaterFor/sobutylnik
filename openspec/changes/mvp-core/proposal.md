# Proposal

## Why

Сейчас у проекта "Собутыльник" нет ни одной реализованной возможности — это greenfield-старт. Нужен минимальный, но цельный продукт: мобильное приложение, где пользователь может найти собеседника/компанию для совместного распития алкоголя рядом с собой прямо сейчас, по аналогии со свайп-механикой Tinder. Без базового набора "профиль → лента → мэтч → чат" продукт не имеет ценности для пользователя, поэтому первый change должен закрыть весь core-цикл целиком, а не отдельный его кусок.

## What Changes

- Регистрация и вход через Telegram (Telegram Login Widget) или по email и паролю (SMS-подтверждение по номеру телефона отложено на стадию после MVP)
- Создание и редактирование профиля: фото (1–3 шт.), имя, возраст, пол, короткое "о себе", предпочитаемый напиток, геопозиция
- Лента карточек потенциальных собутыльников в радиусе поиска (настраиваемый радиус), с фильтром по полу и по статусу готовности ("готов сейчас" / "сегодня" / "на этой неделе")
- Свайп лайк/дизлайк и формирование взаимного мэтча при взаимном лайке
- Список мэтчей и текстовый чат 1-на-1 в реальном времени
- Жалоба на пользователя и блокировка (базовая модерация, без ручной панели модератора в MVP — только сбор жалоб и автоблок после N жалоб)
- Push-уведомления о новом мэтче и новом сообщении в чате

## Capabilities

### New Capabilities

- `user-auth`: регистрация/вход через Telegram или по email и паролю, управление сессией (токены)
- `user-profile`: создание и редактирование профиля пользователя, включая фото и геопозицию
- `discovery-feed`: выдача ленты кандидатов по геопозиции, радиусу, полу и статусу готовности; свайпы
- `matching`: формирование и хранение взаимных мэтчей на основе свайпов
- `chat`: текстовые сообщения 1-на-1 в реальном времени между участниками мэтча
- `moderation`: жалобы на пользователя и блокировка (ручная через жалобу + автоматическая по порогу жалоб)
- `notifications`: push-уведомления о новом мэтче и новом сообщении

### Modified Capabilities

(нет — проект greenfield, модифицировать нечего)

## Impact

- Новый мобильный клиент на React Native + Expo (iOS/Android)
- Новый backend на Go + PostgreSQL (с PostGIS-расширением для геозапросов)
- Реалтайм-канал для чата (WebSocket) и push-доставка (Expo Push Notifications / FCM/APNs через Expo)
- Инфраструктура: деплой backend + PostgreSQL на один VPS (1 vCPU / 1GB RAM / 10GB SSD), без Docker на старте — нужен swap-файл, т.к. его сейчас нет
- Хранилище фото (внешний объектный сторедж, т.к. 10GB SSD и 1GB RAM не рассчитаны на локальное хранение и обработку медиа)
- Новые зависимости: Telegram Login Widget (аутентификация через Telegram), геоиндексация (PostGIS), push-провайдер (Expo/FCM/APNs). SMS-провайдер для OTP не требуется в этом change — отложен на стадию после MVP
