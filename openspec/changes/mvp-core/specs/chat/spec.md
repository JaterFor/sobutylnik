# Spec Delta

## Purpose

Обеспечивает обмен текстовыми сообщениями в реальном времени между двумя пользователями, состоящими в активном мэтче.

## ADDED Requirements

### Requirement: Отправка и получение сообщений в реальном времени
Система ДОЛЖНА доставлять текстовые сообщения между участниками активного мэтча в реальном времени, пока оба подключены.

#### Scenario: Оба участника онлайн
- **WHEN** пользователь отправляет текстовое сообщение собеседнику по активному мэтчу, и собеседник подключён к чату
- **THEN** сообщение доставляется собеседнику практически мгновенно и отображается в его чате

#### Scenario: Собеседник оффлайн
- **WHEN** пользователь отправляет сообщение, а собеседник не подключён в данный момент
- **THEN** система сохраняет сообщение и доставляет его при следующем подключении собеседника, а также отправляет push-уведомление

#### Scenario: Попытка отправки сообщения вне мэтча
- **WHEN** пользователь пытается отправить сообщение пользователю, с которым у него нет активного мэтча
- **THEN** система отклоняет отправку сообщения

### Requirement: История сообщений чата
Система ДОЛЖНА сохранять историю сообщений чата и предоставлять её участникам мэтча при открытии чата.

#### Scenario: Открытие существующего чата
- **WHEN** пользователь открывает чат с активным мэтчем, в котором уже есть сообщения
- **THEN** система возвращает сообщения в хронологическом порядке

#### Scenario: Доступ к истории после разрыва мэтча
- **WHEN** мэтч был разорван (unmatch)
- **THEN** ни один из бывших участников больше не может получить доступ к истории этого чата через API

### Requirement: Статус прочтения сообщения
Система ДОЛЖНА отмечать сообщение как прочитанное, когда получатель открывает чат с этим сообщением.

#### Scenario: Сообщение прочитано
- **WHEN** получатель открывает чат, содержащий непрочитанные сообщения
- **THEN** система помечает эти сообщения прочитанными и уведомляет отправителя об обновлении статуса
