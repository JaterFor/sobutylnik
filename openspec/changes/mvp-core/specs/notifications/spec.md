# Spec Delta

## Purpose

Отправляет пользователю push-уведомления о новом мэтче и новом сообщении в чате, когда он не находится в приложении.

## ADDED Requirements

### Requirement: Push-уведомление о новом мэтче
Система ДОЛЖНА отправлять push-уведомление обоим участникам, когда между ними формируется новый мэтч.

#### Scenario: Пользователь не в приложении в момент мэтча
- **WHEN** формируется новый мэтч, и один из участников не имеет активного соединения с приложением
- **THEN** система отправляет этому участнику push-уведомление о новом мэтче

#### Scenario: Пользователь не дал разрешение на push-уведомления
- **WHEN** у пользователя не предоставлено разрешение на push-уведомления
- **THEN** система не пытается отправить push и не считает это ошибкой

### Requirement: Push-уведомление о новом сообщении
Система ДОЛЖНА отправлять push-уведомление получателю нового сообщения в чате, если получатель не находится в этом чате в момент отправки.

#### Scenario: Получатель не в чате
- **WHEN** приходит новое сообщение, а получатель не имеет открытого активного соединения с этим чатом
- **THEN** система отправляет push-уведомление с указанием отправителя, без полного текста чувствительного содержимого в теле уведомления

#### Scenario: Получатель уже находится в чате
- **WHEN** получатель в момент отправки сообщения имеет открытое активное соединение с этим чатом
- **THEN** система не отправляет push-уведомление, так как сообщение уже доставлено в реальном времени

### Requirement: Регистрация push-токена устройства
Система ДОЛЖНА принимать и обновлять push-токен устройства пользователя для доставки уведомлений.

#### Scenario: Первая регистрация токена
- **WHEN** пользователь впервые предоставляет разрешение на push-уведомления на устройстве
- **THEN** система сохраняет push-токен устройства, привязанный к учётной записи пользователя

#### Scenario: Токен устройства более недействителен
- **WHEN** попытка доставки push-уведомления возвращает ошибку о недействительности токена устройства
- **THEN** система помечает этот токен недействительным и прекращает попытки отправки на него
