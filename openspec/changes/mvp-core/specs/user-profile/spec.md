# Spec Delta

## Purpose

Позволяет аутентифицированному пользователю создать, заполнить и редактировать профиль, по которому его видят другие пользователи в ленте.

## ADDED Requirements

### Requirement: Создание и обязательные поля профиля
Система ДОЛЖНА требовать заполнение обязательных полей профиля (минимум одна фотография, имя, возраст, пол) прежде чем профиль станет видимым в ленте других пользователей.

#### Scenario: Профиль с обязательными полями
- **WHEN** пользователь заполняет имя, возраст, пол и загружает хотя бы одну фотографию
- **THEN** система сохраняет профиль и делает его доступным для показа в ленте других пользователей

#### Scenario: Профиль без обязательных полей
- **WHEN** пользователь пытается завершить заполнение профиля без фотографии, имени, возраста или пола
- **THEN** система отклоняет сохранение и указывает, какие поля не заполнены

#### Scenario: Возраст младше допустимого
- **WHEN** пользователь указывает возраст младше 18 лет
- **THEN** система отклоняет сохранение профиля с ошибкой о минимальном возрасте

### Requirement: Фотографии профиля
Система ДОЛЖНА позволять загружать от 1 до 3 фотографий, заменять и удалять их, определяя одну фотографию как основную.

#### Scenario: Загрузка фотографии
- **WHEN** пользователь загружает фотографию в допустимом формате и размере
- **THEN** система сохраняет фотографию и привязывает её к профилю пользователя

#### Scenario: Превышение лимита фотографий
- **WHEN** пользователь пытается загрузить четвёртую фотографию
- **THEN** система отклоняет загрузку с сообщением о достижении лимита в 3 фотографии

#### Scenario: Удаление единственной фотографии
- **WHEN** пользователь пытается удалить последнюю оставшуюся фотографию профиля
- **THEN** система отклоняет удаление, так как профиль обязан иметь хотя бы одну фотографию

### Requirement: Редактирование необязательных полей
Система ДОЛЖНА позволять редактировать описание "о себе", предпочитаемый напиток и статус готовности к встрече независимо от остальных полей профиля.

#### Scenario: Обновление описания "о себе"
- **WHEN** пользователь изменяет текст "о себе" в пределах допустимой длины
- **THEN** система сохраняет новое значение и применяет его при следующем показе профиля в ленте

#### Scenario: Превышение длины описания
- **WHEN** пользователь вводит текст "о себе" длиннее установленного лимита символов
- **THEN** система отклоняет сохранение с указанием лимита

### Requirement: Геопозиция профиля
Система ДОЛЖНА сохранять текущую геопозицию пользователя (с его согласия) для использования в поиске собутыльников поблизости.

#### Scenario: Предоставлен доступ к геопозиции
- **WHEN** пользователь предоставляет приложению доступ к геолокации и позиция определена
- **THEN** система сохраняет координаты как текущую позицию профиля

#### Scenario: Доступ к геопозиции не предоставлен
- **WHEN** пользователь не предоставил доступ к геолокации
- **THEN** система не делает профиль доступным в ленте по геопоиску и сообщает пользователю, что для участия в поиске нужна геопозиция
