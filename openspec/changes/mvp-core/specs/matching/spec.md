# Spec Delta

## Purpose

Определяет взаимные мэтчи на основе лайков в ленте и предоставляет пользователю список его текущих мэтчей.

## ADDED Requirements

### Requirement: Формирование мэтча при взаимном лайке
Система ДОЛЖНА создавать мэтч между двумя пользователями, когда оба поставили друг другу лайк.

#### Scenario: Второй пользователь лайкает в ответ
- **WHEN** пользователь А уже лайкнул пользователя Б, и пользователь Б лайкает пользователя А
- **THEN** система создаёт мэтч между ними и уведомляет обоих пользователей о новом мэтче

#### Scenario: Лайк без взаимности
- **WHEN** пользователь А лайкает пользователя Б, а пользователь Б ещё не оценивал пользователя А
- **THEN** мэтч не создаётся, пока пользователь Б тоже не поставит лайк

### Requirement: Список мэтчей пользователя
Система ДОЛЖНА предоставлять пользователю список всех его активных мэтчей, отсортированный по времени последней активности.

#### Scenario: Просмотр списка мэтчей
- **WHEN** пользователь открывает список мэтчей
- **THEN** система возвращает все активные мэтчи пользователя с базовой информацией о собеседнике (фото, имя)

#### Scenario: Мэтч без сообщений
- **WHEN** мэтч только что создан и сообщений ещё не было
- **THEN** он отображается в списке мэтчей как новый, без превью последнего сообщения

### Requirement: Разрыв мэтча
Система ДОЛЖНА позволять любому из участников мэтча разорвать его (unmatch), после чего мэтч и связанный чат становятся недоступны обеим сторонам.

#### Scenario: Один из пользователей разрывает мэтч
- **WHEN** один из участников мэтча инициирует unmatch
- **THEN** система помечает мэтч неактивным, скрывает его из списков мэтчей и чатов обоих пользователей

#### Scenario: Попытка повторного взаимодействия после разрыва
- **WHEN** пользователи ранее были в разорванном мэтче и снова встречаются в ленте
- **THEN** система обрабатывает их как новых друг для друга кандидатов и допускает повторный свайп
