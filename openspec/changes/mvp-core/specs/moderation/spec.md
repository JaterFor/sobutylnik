# Spec Delta

## Purpose

Даёт пользователям возможность пожаловаться на другого пользователя и заблокировать его, а также автоматически ограничивает видимость пользователей, набравших много жалоб.

## ADDED Requirements

### Requirement: Жалоба на пользователя
Система ДОЛЖНА позволять пользователю подать жалобу на другого пользователя с указанием причины.

#### Scenario: Подача жалобы
- **WHEN** пользователь подаёт жалобу на другого пользователя, с которым у него есть мэтч или контакт в ленте, указывая причину из предустановленного списка
- **THEN** система сохраняет жалобу, связывая её с жалующимся, объектом жалобы и причиной

#### Scenario: Повторная жалоба на одного и того же пользователя
- **WHEN** пользователь пытается повторно пожаловаться на того же пользователя, на которого уже подавал жалобу ранее
- **THEN** система отклоняет повторную жалобу, не создавая дубликат

### Requirement: Блокировка пользователя
Система ДОЛЖНА позволять пользователю заблокировать другого пользователя, после чего они больше не видят друг друга ни в ленте, ни в чатах.

#### Scenario: Блокировка из чата или мэтча
- **WHEN** пользователь блокирует собеседника по активному мэтчу
- **THEN** система разрывает связанный мэтч, скрывает чат для обеих сторон и исключает заблокированного из будущей выдачи ленты блокирующего

#### Scenario: Попытка взаимодействия после блокировки
- **WHEN** заблокированный пользователь пытается отправить сообщение или лайк заблокировавшему его пользователю
- **THEN** система отклоняет действие без уведомления заблокированного о факте блокировки

### Requirement: Автоматическое ограничение по количеству жалоб
Система ДОЛЖНА автоматически скрывать профиль пользователя из ленты и запрещать ему отправку сообщений после достижения установленного порога уникальных жалоб от разных пользователей.

#### Scenario: Достигнут порог жалоб
- **WHEN** количество уникальных жалоб на пользователя достигает установленного порога
- **THEN** система переводит профиль пользователя в статус ограниченного доступа: скрывает его из лент других пользователей и блокирует отправку новых сообщений

#### Scenario: Жалобы ниже порога
- **WHEN** количество жалоб на пользователя меньше установленного порога
- **THEN** профиль пользователя продолжает отображаться в лентах без ограничений
